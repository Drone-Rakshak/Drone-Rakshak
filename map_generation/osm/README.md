# OpenStreetMap Integration

Drone Rakshak uses OpenStreetMap/Overpass data through the
`ros2/src/drone_map_manager` ROS 2 package.

The package contains the OSM parsing, Overpass querying, geometry,
mesh generation, and Gazebo world-generation components.

This directory is reserved for standalone OSM/map-generation
utilities that are not part of the ROS 2 package.
